## August 8, 2026

- <VPBadge type='tip'>Connect plugin</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Managed Bedrock identity is now zero-config and understands Connect's signed principal v2.** Releases 0.14.0 and 0.15.0 added generated verifier defaults and the newer identity protocol; 0.15.1 then isolated stale Watch proposals but was superseded after its release assets changed during a retry. Install [0.15.3](https://github.com/minekube/connect-java/releases/tag/0.15.3), which contains all three changes with stable published artifacts.
- <VPBadge type='tip'>Connect plugin</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Login plugins can cooperate with Connect without hanging authenticated players or replacing their skin data.** Connect 0.13.0 published a stable `connect-player` channel marker and 0.13.1 re-asserted Connect's login decision after premium-autologin plugins; install [0.15.3](https://github.com/minekube/connect-java/releases/tag/0.15.3), which contains both changes. The [login-plugin guide](/guide/login-plugins) documents the remaining ordering limits.
- <VPBadge type='tip'>Connect plugin</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Spigot now reports useful diagnostics when a server update changes the internal mappings Connect needs.** Added in 0.12.7 and included in [0.15.3](https://github.com/minekube/connect-java/releases/tag/0.15.3).

## August 7, 2026

- <VPBadge type='tip'>Gate</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Current Bedrock clients can join Gate again, and Connect-routed Bedrock identity uses the frozen signed-principal protocol without logging raw identities.** Upgrade to [Gate v0.71.1](https://github.com/minekube/gate/releases/tag/v0.71.1), which contains the identity work from v0.71.0 and the current-client compatibility fix.
- <VPBadge type='tip'>GeyserLite</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **GeyserLite exposes verified Bedrock ingress to embedded and subprocess consumers and includes the latest upstream Bedrock compatibility fixes.** The authenticated ingress API shipped in v0.5.0 and the upstream compatibility updates followed in v0.5.1 and v0.5.2; install [v0.5.2](https://github.com/minekube/geyserlite/releases/tag/v0.5.2).

## August 4, 2026

- <VPBadge type='tip'>Connect</VPBadge> <VPBadge type='info'>Live</VPBadge> **Every Connect endpoint now accepts Microsoft/Xbox-authenticated Bedrock players without requiring a linked Java account by default.** An authoritative link still preserves the linked Java identity; an unlinked player receives a stable native Bedrock/XUID-derived identity. Offline/cracked Bedrock remains unsupported, and cracked Java remains a separate endpoint opt-in. Deployed across the hosted Connect service on August 4. (Internal repository, no public link.)
