## August 24, 2026

- <VPBadge type='tip'>Connect plugin</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Bedrock identity handling is safer on multi-injector servers and survives plugin reloads.** Connect 0.15.4 scopes Bedrock principal admission to Bedrock connections, 0.15.6 recovers the admission coordinator after a plugin reload instead of dropping Bedrock joins, 0.15.8 shares one coordinator across all injectors, and 0.15.9 applies an interim default that generates a version-0 Bedrock principal with a warning until the next identity producer ships. Install [0.15.9](https://github.com/minekube/connect-java/releases/tag/0.15.9).
- <VPBadge type='tip'>GeyserLite</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **GeyserLite tracks current Bedrock clients again through a long chain of upstream compatibility updates.** Releases v0.5.3 through v0.5.21 (August 9–24) pull in repeated Geyser protocol updates; install [v0.5.21](https://github.com/minekube/geyserlite/releases/tag/v0.5.21), which contains them all with builds attached. Several intermediate releases were published without downloadable builds and should not be pinned.
- <VPBadge type='tip'>GeyserLite</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Player skins decode without AWT, which unblocks the native-image builds.** v0.5.10 decodes skins without AWT, and v0.5.21 removes AWT from the skin provider's class initialization so native releases can ship again; install [v0.5.21](https://github.com/minekube/geyserlite/releases/tag/v0.5.21).

## August 22, 2026

- <VPBadge type='tip'>Craftless</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Craftless CLI and daemon fixes in [v0.3.7](https://github.com/minekube/craftless/releases/tag/v0.3.7):** the CLI preserves schema-defined string request fields, the daemon runs the newest packaged client lane inside Docker, and latest-Fabric canary failures now report the actionable cause instead of a bare failure.

## August 21, 2026

- <VPBadge type='tip'>Connect plugin</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Session proposals report the real rejection reason, and endpoints without an org are admitted under Bedrock identity enforcement.** Connect 0.15.7 logs the exception message when a session proposal is rejected and admits org-less endpoints; 0.15.5 preserves tunnel delivery and late wrappers. Install [0.15.9](https://github.com/minekube/connect-java/releases/tag/0.15.9), which contains both.

## August 17, 2026

- <VPBadge type='tip'>Gate</VPBadge> <VPBadge type='warning'>Upgrade</VPBadge> **Gate applies the linked Floodgate Java identity on its direct listener.** [v0.71.3](https://github.com/minekube/gate/releases/tag/v0.71.3) fixes Bedrock players with a linked Java account joining through Gate's direct listener, and v0.71.2 also updates Gate's bundled GeyserLite to v0.5.11; install v0.71.3, which contains both.
