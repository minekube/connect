Minekube Connect is built in the open. This page thanks everyone whose work makes the website and the docs possible.

## Website design and front end

The current Minekube Connect website was designed and built by **DarkZmaj** as a community contribution. That covers the home page, the documentation design and navigation, search, the plans, changelog, blog and team pages, and the move of the docs to [Astro Starlight](https://starlight.astro.build/).

- GitHub: [@DarkZmaj](https://github.com/darkzmaj)
- Website: [darkzmaj.eu](https://darkzmaj.eu)

## Documentation and content

The guides, blog posts and changelog are written by the [Minekube team](/team) and contributors. Every docs page has an **Edit page** link at the bottom if you want to suggest a change.

## Video

The video on the home page, *Self-Host a Minecraft Server Without Port Forwarding Using MineKube Connect*, is by [KasaiSora](https://www.youtube.com/@KasaiSora).

## Community

The quotes on the home page come from members of the Minekube community. Thank you for building with Connect and Gate, and for telling us about it.

## Open source

The site is built with these projects:

- [Astro](https://astro.build/) and [Starlight](https://starlight.astro.build/), the site framework and documentation theme
- [Pagefind](https://pagefind.app/), the search index behind the search dialog
- [Vue](https://vuejs.org/), for the plans, positions and globe components
- [Tailwind CSS](https://tailwindcss.com/) and [Expressive Code](https://expressive-code.com/), for styling and code blocks
- [Lenis](https://lenis.darkroom.engineering/), for smooth scrolling
- [globe.gl](https://globe.gl/) and [three-globe](https://github.com/vasturiano/three-globe), for the edge locations globe
- [Inter](https://rsms.me/inter/), [Archivo](https://github.com/Omnibus-Type/Archivo) and [Geist Mono](https://vercel.com/font), the typefaces, served through [Fontsource](https://fontsource.org/)

The changelog timeline is adapted from the [Cloudflare Docs](https://github.com/cloudflare/cloudflare-docs) changelog components (MIT). Licence details are in `THIRD_PARTY_NOTICES.md` in the [repository](https://github.com/minekube/connect/tree/main/.web).

## Contribute

Found something to improve? The website lives in the [`minekube/connect`](https://github.com/minekube/connect) repository, and help is welcome in the [Minekube Discord](https://minekube.com/discord).
